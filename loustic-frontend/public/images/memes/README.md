# Dossier d'images pour Mess Meme 😂

Déposez ici les images de vos mèmes !

## Format recommandé :
- Nom de fichier : `meme_1.jpg`, `meme_2.jpg`, `meme_3.png`, `meme_4.webp` (ou n'importe quel nom déclaré dans `src/data/messmeme.json`).
- Format : JPG, PNG, WEBP, GIF ou SVG.
- Dimensions conseillées : Entre 500x500px et 1080x1080px (ratio carré ou 4:3).

L'application charge automatiquement les images depuis `/images/memes/<nom_du_fichier>`.
Si une image n'est pas encore présente, un visuel illustré de fallback s'affiche automatiquement avec le titre du mème !
