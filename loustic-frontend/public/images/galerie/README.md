# Dossier d'images pour Galerie 🎨

Déposez ici les œuvres d'art et tableaux poétiques pour le jeu Galerie !

## Format recommandé :
- Nom de fichier : `art_1.jpg`, `art_2.png`, `art_3.webp` (ou les chemins déclarés dans `src/data/galerie.json`).
- Format : JPG, PNG, WEBP ou SVG.
- Dimensions conseillées : Format carte ou portrait 600x800px ou carré 800x800px.

L'application charge les œuvres d'art depuis ce dossier `/images/galerie/`.
Si une image n'est pas encore déposée, une carte d'art illustrée de fallback avec l'ambiance et les emojis s'affiche automatiquement !
